# Zenn プロファイル

この例は `syntax="zenn"` で表示しています。
通常のソース内改行も表示に反映します。

:::message
メッセージ、GFM の表、数式、Zenn のインライン脚注を使えます。
:::

:::details 詳しい説明
このプロファイルでは Mintlify タグと Inkstream の quiz・chart・tree フェンスを展開しません。
:::
