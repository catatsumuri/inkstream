# 基本の Markdown

**太字**、*強調*、[リンク](https://example.com)、`インラインコード`を使った文書です。

- ソースを読む
- プレビューと比べる

> 通常の引用です。

```js
const message = "Hello, Markdown!";
```

## プロファイルを比較する

**all** に切り替えると、このタグがコールアウトになります。**basic** と **zenn** では文字列のままです。

<Note>コンポーネント構文は必要に応じて使えます。</Note>

次の表には **all** または **zenn**（GFM）が必要です。

| プロファイル | GFM |
| --- | --- |
| basic | なし |
| zenn | あり |
| all | あり |
